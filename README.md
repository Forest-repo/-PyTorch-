# [牛_奶奶](https://space.bilibili.com/492738377)

这个仓库是一个面向 **PyTorch 初学者** 的配套教学仓库，内容按教程拆分成两个阶段：

1. [【PyTorch】手把手教你跑通第一个神经网络](https://www.bilibili.com/video/BV1UR4y1t7Cm?share_source=copy_web)
2. [【PyTorch】如何让网络优雅地分类猫猫狗狗](https://www.bilibili.com/video/BV1fS4y1Q7Ph/)

## 目录说明

### `01_手把手教你跑通第一个神经网络`
- 使用一组循序渐进的脚本讲解深度学习训练基本流程：`Dataset`、`DataLoader`、`Model`、`Optimizer`、`Train`。
- 适合作为从零到一理解 PyTorch 训练管线的入门实践。

### `02_如何让网络优雅地分类猫猫狗狗`
- 基于 Dogs vs Cats 任务做一个更完整的图像分类项目。
- 包含数据集拆分、训练代码模板、指标统计与 TensorBoard 记录示例。

## 使用建议

- 建议按目录顺序学习，从 `01` 到 `02`。
- 每个脚本都带有较多注释，适合边读边跑。
- 运行前请先准备好对应数据集，并按脚本内默认路径放置。
